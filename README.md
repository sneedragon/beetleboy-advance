# BeetleBoy Advance SP

A powergaming frontend for the beetle game on [remilia.net](https://www.remilia.net).

**Play at [beetle.sevensevenseven.net](https://beetle.sevensevenseven.net)**

## Features

- Full inventory overview with icons and rarity colors
- Beetle collection album / beetledex
- All recipes in the game — searchable, clickable to autofill crafting slots
- Mass-crafting with repeat counts
- "Crunch all Junk" button — converts your junk pile to cubes in one click
- Embedded beetle wiki
- Chatroom with item linking, emoji reactions, and replies
- Desktop notifications when actions come off cooldown
- Rare drop and trophy announcements in chat
